---
name: Infographic Design Quality Standards
description: CRITICAL design rules for LinkedIn infographics. One story per post, no emoji, SVG icons only, large text, no content overflow, visible decorative elements, proper connecting lines.
type: feedback
---

Each infographic post must tell ONE story, deeply and well. NOT a daily digest.

**Visual Design Rules (NEVER violate):**
1. NO EMOJI for icons. Use inline SVG line drawings instead. SVGs should be clean, minimal, monochrome line art. Icons ARE allowed and encouraged when appropriate, just not emoji.
2. NO neon glow effects, no box-shadow glow. Subtle shadows only.
3. NO DASHES anywhere in text (-, --, —, –). Rewrite sentences to avoid them.
4. Large typography: hero numbers 160px+ weight 900, stat numbers 56px+ weight 900, body text minimum 18px, labels minimum 14px weight 300 uppercase.
5. NO content overflow. Everything must fit within 1080x1350. Test layouts mentally before committing.
6. Timelines MUST have a visible connecting line (4px+ SVG stroke) between all nodes. Never floating disconnected circles.
7. Pyramid/hierarchy shapes must use proper SVG trapezoids that actually look like a triangle/pyramid. Top layer must be wide enough for text.
8. Network/constellation diagrams: nodes minimum 100px diameter with solid fills (not thin borders). Connecting lines minimum 3px stroke. Labels minimum 18px.
9. Background decorative elements (rings, grids, patterns) must be VISIBLE. Use opacity 0.10 to 0.25, not 0.03.
10. SVG data visualization for charts (area charts, bar charts). Not colored divs.
11. Add decorative SVG elements for visual richness: dot grids, circuit traces, flowing lines, geometric mesh, gradient orbs, wave patterns. Each post should have some visual texture.
12. Color: restrained palette per post. One accent color + white + grays. No rainbow.
13. Generous whitespace. Premium editorial feel.

**Why:** User reviewed multiple rounds of infographics. Emoji looks cheap. Thin/faint elements are invisible. Text walls defeat the purpose. Content overflow looks broken. Each post should look like a top design agency made it, not AI.

**How to apply:** These rules must be in the /infographic preview skill instructions so Claude follows them every time it designs an infographic. Not just for fixes, but for ALL future posts.
