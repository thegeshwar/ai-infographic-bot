---
name: Caption single newlines and source links
description: Infographic captions must use single newlines (not double) and every source must have a URL link cited
type: feedback
---

Captions must use SINGLE newlines (\n) between paragraphs, never double newlines (\n\n). LinkedIn renders one newline as a paragraph break; double creates excessive whitespace.

Every caption MUST end with a Sources: section before hashtags, with every source cited including its full URL. Format: `Sources:\nSourceName — https://full-url.com`

**Why:** User audited all 8 generated captions on 2026-03-27. Every single one used \n\n. Only 2 of 8 had source links in the caption. This is a hard rule — no post can go out without sourced links.

**How to apply:** When generating any infographic caption (personal or company), enforce single newlines and mandatory source URLs. Check before rendering.
