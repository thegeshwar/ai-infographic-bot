Every infographic caption MUST cite ALL sources at the end. Every single one.

**Why:** The user requires full transparency on where information comes from. No exceptions.

**How to apply:** At the end of every LinkedIn caption (before hashtags), add a "Sources:" section listing every article, report, or data source used to research and create the post. Include the publication name and URL where possible.
