Design feedback accumulated across 4+ review rounds on 2026-03-25.

**No generic boxes.** Max 1-2 per design. Use left-accent borders, sharp corners, or full-bleed color blocks only. NEVER border-radius 8px+ with border 1px solid. That looks AI-generated.

**Why:** User explicitly rejected card-grid layouts across multiple rounds. Called rounded-corner boxes "gay as fuck" and "boring."

**How to apply:** Before rendering, count boxes. If more than 2, redesign without them. Use open editorial layouts with divider lines and whitespace.

---

**Real company logos.** When mentioning companies (Google, NVIDIA, Samsung, OpenAI, etc.), include inline SVG recreations of their logos. Not generic icons.

**Why:** User wants posts to feel real and authentic, not like generic AI content.

**How to apply:** Build SVG logo paths for major tech companies. Keep at 32-48px. Place inline with company names.

---

**Balanced typography.** Heroes 120-140px max. Labels 18-22px. Body text 22-26px. Max 7:1 ratio between largest and smallest text.

**Why:** User noticed big numbers were dominating while labels were invisible on mobile. Confirmed across all 10 posts.

**How to apply:** After writing HTML, scan all font-size values. If any label is below 16px or hero is above 140px, fix it.

---

**SVG topic icon grid backgrounds.** Repeating pattern of muted topic-related SVG icons tiled across background. Plus gradient orbs or concentric rings for depth.

**Why:** User requested this as a signature design element. Adds visual texture without being distracting.

**How to apply:** Every post gets an SVG pattern element with 2-4 thematic icons at 0.04-0.08 opacity.

---

**Fill available space.** If there is empty space, make text bigger rather than leaving whitespace. But don't stretch text to full width — keep text blocks at 700-900px max-width.

**Why:** User noticed posts had wasted empty areas while text was small.
